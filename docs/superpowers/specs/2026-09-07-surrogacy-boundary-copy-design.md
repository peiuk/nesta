# 格鲁吉亚代孕协调边界文案（2026-09-07）

对应公开首页与隐私页：明确业务为格鲁吉亚代孕相关协调，并写清非医疗、非律所边界。不改门户交互与 API。

## 背景

站点已有静谧自然首页与私密门户，但公开文案偏「通用生育协调」，意向客户不易识别代孕业务；合规边界仅在隐私页一句带过。业务方确认：**公开页直接使用「代孕」表述（口径 A）**，并采用**轻量改写（方案 1）**——以文案与一小段边界说明为主，不大改版式。

## 已确认决策

- 公开口径：**直接写明格鲁吉亚代孕协调**（中英对等）
- 改法：**轻量改写**首页 + 强化隐私「服务边界」；不新增沉重免责整页
- 语气：**克制、可信**；不写成功率、不虚假医院/律师背书、不写价格承诺
- 试用条保留：「私密试用版」提示仍在

## 范围

**改：**

- `app/page.tsx`：首屏副文、服务区/旅程措辞、新增短「服务边界」区块与可选导航锚点
- `app/privacy/page.tsx`：「服务边界」（及必要时「本版用途」一句）扩写代孕协调定位
- `app/product.css`：仅当边界段需要与现有 `section-intro` / 间距对齐时做极少量样式

**不改：**

- 门户、注册表单字段、API、策略、数据库、部署脚本
- 联系电话/邮箱常量、登录路径
- 主视觉图与整体视觉气质（沿用现有首页设计）

## 首页文案意图

### 首屏

- 保留品牌主视觉与主标题气质（「迈向家庭…」可保留或微调，不改为口号式推销）。
- 副文须出现：**格鲁吉亚代孕相关协调**，并概括协调范围：沟通与评估、与诊所/行程相关的对接、进度与报告记录、出生后手续跟进。
- 小字继续强调：试用版；服务须经个别法律与医疗评估。

### 服务三条（`#care`）

- 保持「私密空间 / 可追溯报告 / 双语沟通」结构。
- 描述可轻点「代孕协调案件」语境，但不夸大权限或结果。

### 旅程（`#journey`）

四步贴代孕协调路径，并保留「因个案与诊所安排而异」：

1. 沟通与评估 — 需求、资料与**服务是否适用**的初步了解（非法律结论）
2. 计划与协调 — 诊所安排、费用范围归属、各方职责说明
3. 记录与随访 — 周期/检查/沟通记录与经复核报告交付
4. 出生后支持 — 出生登记、亲权与旅行文件等手续**跟进**（非代理出具法律意见）

### 服务边界（新，`#boundaries`）

放在旅程与 CTA 之间，约 2–3 句，中英 `t()`：

- 初禾提供的是**代孕相关协调与进度记录**，不是医疗机构，也不是律师事务所。
- 不提供医疗诊断、法律资格判断、紧急医疗联络或付款结算。
- 具体诊疗由合作/接诊医疗机构负责；法律事务由持牌专业人士确认；能否开展服务须个案评估；**不承诺结果**。

桌面导航可增加链至 `#boundaries`；移动端可不显示该链（沿用 `nav-desk` 模式），避免顶栏拥挤。

### CTA（`#contact`）

- 可轻改一句：登录或电话/邮件咨询前，可先阅读服务边界。
- 不在此堆叠完整法律文本。

## 隐私页

- **服务边界**：明确业务为格鲁吉亚代孕协调；重申非医疗/非律所/无诊断与资格结论/无紧急医疗与付款；本站用于档案、授权与报告交付；正式业务上线前主体与合规安排另定。
- **本版用途**（可选一句）：试用仍要求虚构/测试资料，不上传真实敏感信息（与现文一致即可）。
- 其余章节（登录、存储、试用后处理）保持，除非需一句交叉引用「见服务边界」。

## 禁止表述

- 成功率、保证怀孕/出生、保证证件或国籍结果
- 「我们提供医疗/法律服务」或等同表述
- 未核实的医院、律师、成功率背书
- 具体报价或「包成功」套餐话术

## 验收

- 中英文切换下，首页首屏与边界段均出现代孕协调定位及非医疗/非律所说明。
- 隐私「服务边界」与首页边界语义一致，无互相矛盾。
- 桌面可从导航或页内到达 `#boundaries`；移动端布局不回退到拥挤顶栏。
- 不改动 `/portal` 行为与 API。
