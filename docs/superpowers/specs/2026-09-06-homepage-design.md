# 首页设计感升级（2026-09-06）

对应官网落地页 `app/page.tsx` + `app/product.css`（及必要的字体引入）。不改门户、API、文案主旨。

## 背景

当前首页是浅绿渐变 + 文字堆叠，无真实视觉锚点，展示字体偏系统默认（Segoe / 微软雅黑），服务区与旅程区偏「信息卡片」观感，整体干净但设计感弱。

品牌定位：格鲁吉亚生育服务协调（代孕中介业务语境下的协调站），私密试用版；语气须克制、可信，不得新增虚假医疗/法律能力承诺。

## 已确认决策

- 气质：**静谧自然**（柔光绿植 / 晨雾，克制、可信）
- 范围：**整页统一气质**（首屏加强，服务 / 旅程 / CTA / 页脚同一套视觉）
- 结构：**全幅氛围首屏 + 轻量分区**（方案 1）
- 家庭意象：**不以宝宝 / 全家福为主视觉**；「迈向家庭」留在文案与细节点缀，不靠情感海报推销

## 范围

**改：**

- `app/page.tsx` 结构与 class（保留区块与链接）
- `app/product.css` 首页相关样式；必要时微调 `:root` 字体变量（仅影响展示，不改门户交互语义）
- `app/layout.tsx`（或等价处）引入 Google Fonts / `next/font`
- `public/` 新增一张全幅主视觉图

**不改：**

- 门户、注册、API、策略、数据库
- 中英切换机制与试用版提示存在性
- `/portal`、`/privacy`、登出路径
- 不新增统计条、徽章浮层、虚假案例数据

## 视觉系统

### 色

- 主色保持深绿系（现有 `--primary: #284e3c` 可沿用）
- 页面底：雾绿 / 晨光浅底，避免纯平单色；避免奶油+#terracotta、避免紫系、避免默认深色模式营销风
- CTA 收束带：全宽深绿，白字

### 字体

- 展示（品牌大字、h1/h2、旅程序号）：人文衬线，如 **Fraunces** 或 **Source Serif 4**（择一，经 `next/font` 或 Google Fonts 引入）
- 正文 / 导航：清晰无衬线，如 **Source Sans 3**
- 禁止把 Inter / Roboto / Arial / 系统默认栈当作首页主展示字体

### 主视觉

- 一张真实感绿植 / 柔光晨雾照片，放 `public/`（例如 `public/hero-canopy.jpg`）
- 用作首屏 **edge-to-edge 背景平面**，不是 inset 卡片、不是侧栏小图、不是拼贴
- **禁止**：婴儿特写、孕妇大特写、幸福全家福海报、浮在图上的促销徽章 / 信息芯片

### 动效（至少 2–3 处，尊重 `prefers-reduced-motion`）

1. 首屏：品牌与标题轻微上浮淡入
2. 背景图极慢 Ken Burns（缩放 / 平移幅度极小）
3. 旅程四步：滚动进入时依次轻微显现

## 分区设计

### 顶栏

- 叠在首屏图上：半透明 / 毛玻璃浅底，文字保持可读
- 内容：`Brand`、锚点导航、语言切换、客户登录
- 顶栏之上或之内保留试用版提示（现有 `pilot-strip` 可改为更轻的叠层条，不抢品牌）

### 首屏（一个构图）

仅含：

1. 大品牌信号「初禾 FIRSTLEAF」（hero 级，不得被标题压过）
2. 一句主标题（现有中英意涵保留）
3. 一句支持说明
4. 一组 CTA：主按钮进 `/portal`，次链接锚到 `#journey`
5. 试用脚注一行

图上叠一层低对比深绿 / 雾色渐变遮罩，保证白 / 深字对比度。不做服务三点、不做统计、不做浮层标签。

### 服务条（`#care`）

- 三点内容保留
- **去卡片化**：无边框底板、无阴影、无圆角色块；大留白；细竖线或极淡编号 + 缩小线描图标
- 桌面三列，窄屏单列

### 服务旅程（`#journey`）

- 四步叙事与文案保留
- 大号浅色衬线编号作节奏；步骤间细线分隔，不做四张卡片
- 背景为同色系更静的雾绿 / 浅底

### 底部 CTA

- 全宽深绿（可极淡纹理），白字标题 + 一句说明 + 单一主按钮「建立我的档案」→ `/portal`
- 不做圆角 inset 色块条带卡片

### 页脚

- Brand + 定位短句 + 隐私链接；分隔线极淡；背景贴近页面底色

## 文案与合规边界

- 保留「私密试用版 / 测试资料 / 个别法律与医疗评估」类提示
- 「家庭」只通过既有文案表达（如「迈向家庭的每一步」），不新增宝宝营销语或保证结果的表述
- 不暗示已具备完整医疗、法律或合规资质

## 响应式

- 桌面：全幅首屏可读，品牌优先
- 手机：首屏背景仍满宽；标题字号下调但仍次于品牌层级；服务单列；旅程两列或单列；CTA 按钮全宽可点

## 验证

- 本地 `npm run dev` 打开 `/`：首屏有全幅图与品牌层级；无宝宝主视觉；中英切换正常
- 窄屏与 `prefers-reduced-motion: reduce` 下动效关闭或降为静态
- `npx tsc --noEmit`、`npm run lint` 无新增错误（以当前分支基线为准）

## 备注

实现时若需生成或挑选主视觉图，优先柔光绿植 / 林冠 / 晨雾；若使用 AI 生成图，须检查无人物婴儿、无文字水印、色调与深绿品牌一致。
