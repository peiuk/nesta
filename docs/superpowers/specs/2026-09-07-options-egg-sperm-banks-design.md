# 多元方案与独立精卵库首页表达（2026-09-07）

对应公开首页：并列呈现代孕协调、独立卵子库、独立精子库；说明可按需组合。不改门户 API 与授权规则。

## 背景

业务方确认：服务含**独立精子库与卵子库**供客户选择，并提供**多元化方案**。公开口径与代孕协调**并列可选、可组合（口径 A）**；版式采用**轻量三列（方案 1）**。

## 已确认决策

- 关系：**代孕协调 / 卵子库 / 精子库**并列；客户可按需求组合
- 版式：服务区后新增短节三列，沿用现有首页气质（无推销卡片堆）
- 资料库：强调登录后、**按授权**可见；首页不展示真实供者样本
- 边界：资料库用于协调与知情选择；不作医疗/法律承诺、不写成功率

## 范围

**改：**

- `app/page.tsx`：首屏副文轻补；新节 `#options`；桌面导航链；边界段一句
- `app/product.css`：三列布局与小屏单列（可复用/微调 `service-strip` 模式）

**不改：**

- 门户资料库 API、授权、供者卡片字段
- 隐私页可不动，或仅在服务边界加半句「含独立精卵资料库协调」——优先首页，隐私非必须

## 文案意图

### 首屏

在现有代孕协调副文末（或紧接一句）：可另选或组合独立卵子库、精子库方案。

### 新节 `#options`

- Eyebrow：OPTIONS / 方案选择（中英）
- 标题：如「多元方案，按需组合。」
- 三列：
  1. **代孕协调** — 沟通、行程与诊所对接、进度与报告、出生后手续跟进
  2. **独立卵子库** — 经授权后查看与选择；用于知情选择与协调，非医疗建议
  3. **独立精子库** — 同上
- 节末一句：登录并获批后，资料库按授权开放；具体组合经评估后确认。

### 导航

桌面 `nav-desk` 增加「方案」→ `#options`。

### 边界

现有 `#boundaries` 增一句：独立精卵资料库服务于协调与知情选择，不构成医疗或法律意见。

## 禁止

- 成功率、保证匹配成功、展示可识别供者隐私
- 「医疗级筛查结论由本站作出」等越权表述

## 验收

- 中英下可见三列并列与可组合表述
- 移动端三列不挤在同一行导致难读
- 未改 `/portal` 行为
