# 选卵申请与审批

客户：注册并获批 → 获得有效卵子库授权 → 选择可申请档案 → 提交可选备注 → 在「我的选卵申请」查看处理状态与回复。收藏仍用于记录偏好，不代表申请。待审批申请可撤回；退回或撤回后可重新申请。

管理员：后台「选卵申请」集中审核，待处理数量在导航和首页显示。通过或不通过时须填写客户可见回复。通过表示继续服务协调，不预留供者、不更改供者可用状态，也不构成医疗适配结论。

提交与批准同时检查客户账户、卵子库授权及供者状态。提交、审批、撤回与审计记录在数据库事务中处理；部分唯一索引阻止同一客户对同一供者存在多个待审批/已通过申请。条件更新阻止旧页面覆盖已经处理的结果。客户只能查询和撤回自己的记录，授权过期后仍可在已批准账户内查看自己的申请历史。

新表由 `0003_egg_requests.sql` 发布迁移建立，不在请求处理中执行建表。私密试用的站点访问范围仍仅限所有者；实际客户试用须另行开放相应访问范围。
