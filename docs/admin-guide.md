# 初禾后台 · 私密试用

入口 `/admin`。在登录页用 **ADMIN_EMAIL** 中登记的邮箱收取验证码（与 Portal 相同机制；需 `SESSION_SECRET`，且 `SITE_ORIGIN` 与浏览器地址栏 origin 一致；未配置邮件时本地验证码见控制台 `[firstleaf-otp]`）。后台不会提供角色模拟或绕过身份验证。

## 日常操作

1. **客户与团队**：查看注册资料、批准客户，或将团队账户设为协调员、独立审核员。角色变更清除原有案件身份和资料库授权，需要重新分配。
2. **访问授权**：为客户分别开放卵子库、精子库，填写有效期和理由；可撤销授权。
3. **案件与进度**：选择已批准客户建立案件，分配成员，记录移植、随访、产检预约和阶段变化。案件详情可维护四项证件节点（出生证明、DNA报告、公证、海牙认证）；客户只见状态与日期，内部备注仅协调员和管理员可见。
4. **报告与文件**：在案件内上传原件及可选译件，选择收件客户。独立审核员复核后，协调员发布。客户只看到获准交付给自己的已发布文件。个人资料同样可按文件上传至案件。
5. **供者资料库**：新增或修改合作方供者资料，维护可申请、匹配中、暂不可用、已下架状态及原因。
6. **合作方**：维护 IVF 诊所与月子中心名录（名称、联系方式、备注、启用/停用）；在案件详情为每个案件各绑定最多一家诊所与一家月子中心。停用不解除已有绑定。入口 `#partners`。
7. **客户留言**：集中查看已参与案件的未回复问题，直接回复或进入案件查看背景。
8. **操作记录**：按动作或日期筛选最近 100 条审计记录。

工作台数字来自数据库。报告、问题、预约仅限管理员以协调员身份参与的案件；不会因为后台角色而默认读取其他案件的医疗资料。移除案件成员后，工作台查询立即不再返回该案件资料。

报告中心显示最近 100 份，留言显示最早 100 条未回复记录；首页审批队列显示最早 6 位已提交档案的待审批账户。统计数字不受这些列表上限影响。授权和预约提示覆盖未来 7 天。

后台模块可通过地址中的 `#people`、`#cases`、`#partners`、`#reports` 等直接定位，案件支持 `#cases/<id>`。表格可横向滚动，窄屏使用可收起菜单，所有模块支持中英文。

## 客户更新邮件

管理员或案件协调员保存以下客户可见更新后，系统自动向客户账户邮箱发送通知：

- **报告与文件**：正式发布（包括新版报告）或撤回已发布文件时，仅通知指定收件客户。上传草稿、审核和撤回未发布文件不发信。
- **服务进度**：阶段或周期变化、新增进度节点或预约、证件状态或日期变化时，通知该案件的客户。仅修改证件内部备注不发信。
- **沟通记录**：新增或修改回复时，仅通知该条留言的提问客户。

仅通知当前仍属于该案件、角色为客户且账户已批准的用户；相同邮箱去重。重复保存相同阶段、周期、证件状态／日期或回复不重复发信。邮件正文跟随客户档案的中英文语言设置，包含客户门户登录链接，不包含报告正文、附件、留言内容或内部备注。

邮件复用登录验证码的 Gmail／Resend 配置，无需单独开关。Gmail 需要 `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`GMAIL_REFRESH_TOKEN` 和 `GMAIL_USER`（或 `EMAIL_FROM`）；Resend 需要 `RESEND_API_KEY` 和 `EMAIL_FROM`。配置 `SITE_ORIGIN` 为客户访问的网站地址，邮件链接指向 `/portal`。本地未配置发送服务时仅输出开发日志，不投递真实邮件。

通知在数据保存成功后进入 D1 邮件队列，并在同一请求中立即尝试投递。邮件发送失败不会撤销已保存的更新；系统保留失败记录并按退避时间标记重试。系统不会在没有新请求时自行唤醒队列；管理员可调用 `POST /api/notification-outbox/process`（JSON 可传 `{"limit":20}`，上限 50）处理到期邮件，并检查返回的 `sent`、`failed`、`remaining` 计数及应用日志。此接口应仅由受信任的管理员会话调用，不要公开成无认证的 cron URL。

## 验证与界限

SQLite 集成测试覆盖工作台真实统计、未提交注册排除、授权到期和预约日期范围、非管理员拒绝、案件撤权与私密存储标识隔离，并保留原有报告权限与文件校验测试。

当前为仅测试资料的私密试用。医院与团队接入、正式隐私协议、真实业务准入、生产邮件投递验收及真实患者资料上线流程尚未完成。客户和审核员实际加入还需调整网站的访问范围。
