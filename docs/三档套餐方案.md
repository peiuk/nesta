# 初禾三档套餐方案（成本 + 竞品校准）

## 你的结构是否合理？

**合理。** 这是标准的 Good / Better / Best：
- 基础：剥离住宿与月子，打价格带入门
- 中级：用 PGS +「可移植胚胎的移植安排」做价值跃迁（转化主力）
- 高级：用 30 天月子+住宿做一站式收口

需要改口径的一点：首页与合同不要写「包成功」四个字指活产；写成 **「约定枚数 PGS + 可用可移植胚胎的移植安排」**，胚胎用尽后的重启规则另附。这样既保留你想卖的中级卖点，又和初禾服务边界一致。

以上均未含律师证件、翻译、二次周期、你的人力与获客。

## 中级「胚胎可移植」建议合同写法（要点）

1. 含 PGS N 枚（建议对外写 **6 枚**，超出 $500/枚）  
2. 对筛查后可移植胚胎，在约定周期规则内安排移植，不另收约定内移植协调费  
3. **不保证**着床、活产或性别结果  
4. 胚胎用尽：书面重启选项（补差 / 新促排 / 终止）

## 另计清单（三档都要公示）

供卵供精、机票签证、国内体检、双胎、剖宫、NICU、超出天数的月子/住宿、超出 PGS 枚数。
