# 竞品补充：BABYCOME（格鲁吉亚）

来源：用户提供的 BABYCOME 宣传长图（2026-09-07）  
用途：补充初禾 FIRSTLEAF 定价锚点与套餐结构对照；**公开站仍不照搬「包成功」话术**。

---

## 1. 一句话画像

BABYCOME 用**同一套网格结构**铺多档美元套餐：自选医院低门槛 → 基础 → 包成功 → 指定性别包成功 → 二胎优惠，并给**固定 5 节点付款**与成本拆分表。转化逻辑清晰，偏「报价手册」而非「协调平台」。

---

## 2. 套餐与价格带

| 套餐 | 标价（USD） | 约合人民币* | 卖点 |
|---|---:|---:|---|
| 医院自选 | 8,000（更像启动/协调费） | ~5.8 万 | 客户自选合作医院与单项服务 |
| 基础套餐 | **62,000** | ~45 万 | 全流程协调 + 成本拆分表 |
| 包成功 | **69,000** | ~50 万 | 多次周期直至活产叙事 |

\*按约 7.3 粗算，仅作对照，非实时牌价。

### 典型付款节点（基础 / 包成功结构相似）

以基础 6.2 万美金为例：  
签约 7k → 周期启动 7k → 孕 12 周 11k → 孕 28 周 18k → 分娩 19k  

包成功把**分娩节点抬高**（例：26k），指定性别则全程节点上浮（签约/启动各 10k … 分娩 28k）。

### 基础套餐成本拆分（宣传表常见项）

供卵、IVF/药、PGD、孕母补偿、法律行政等分项列出（例：孕母补偿约 25k 美金量级）——这点对「费用透明」叙事有参考价值。

### 服务流程（9 步）

国内咨询 → 评估 → 匹配供卵/孕母 → 法律签约 → 取卵采精 → 移植 → 产检生产 → 证件 → 回国团圆。

## 3. 对初禾的启示（可学 / 不可学）

### 可学

1. **多档同构**：基础 / 升级 / 老客，卡片字段对齐，方便扫描。  
2. **5 节点付款**：比 8–10 步更易懂；节点与孕周绑定。  
3. **成本拆分表**：增强「钱花在哪」的信任（适合放门户或 PDF，不必放公开首屏）。  
4. **二胎/老客档**：若初禾有回头客，可作门户内隐藏档。

### 不可照搬到公开站（与 firstleaf 规格冲突）

- 「包成功」「指定性别包成功」大字承诺  
- 公开站直接标美元总价作主转化（你们选择门户/克制获客）  
- 暗示机构本身提供医疗成功保证
